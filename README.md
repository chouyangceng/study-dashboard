# 🎯 考研执行看板 · 清华车辆 822

把《清华车辆822考研计划》xlsx 变成**每日可勾选的任务清单 + 自动周复盘**。

## 功能

- 📋 **周任务清单**：从 xlsx 周计划提取的每周任务，按每日时间块（07:00-09:30 / 09:45-11:15 / 13:30-15:00 / 15:15-16:45 / 21:00-22:00）组织
- ✅ **一键勾选**：完成任务打勾，完成率自动计算
- 📊 **周复盘自动化**：完成率 <70% 自动提示"下周减 20% 先补欠账"（对齐计划执行规则）
- 🏁 **周验收标准**：每周围绕 822 能力点设验收项（如"能独立化简方块图"）
- 📏 **执行规则卡**：1000A 正确率分流、A4 大法、降级规则等
- 📅 **每日时间块视图**：按固定作息查看当天任务

## 使用

直接双击打开 `index.html`，数据存于浏览器 localStorage。

## 数据源

`plan-data.js` 从《清华车辆822考研计划_最新大纲重制版.xlsx》的周计划页提取：
- 阶段导航（01页）→ 5 个阶段
- 每日时间表（02页）→ 时间块
- 详细周计划（10页）→ 每周任务
- 执行规则（07页）→ 规则卡

更新计划时只需改 `plan-data.js` 的 `WEEK_PLANS` 数组。
